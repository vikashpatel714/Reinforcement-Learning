1. Probability Foundations for RL

Basics

Probability measures how likely an event is, on a scale from 0 (impossible) to 1 (certain). The set of all possible outcomes is the sample space S. An event is a subset of S.

P(A) = favourable outcomes / total outcomes (equally likely case)

Axioms: P(A) ≥ 0; P(S) = 1; for mutually exclusive events P(A ∪ B) = P(A) + P(B).

Useful rules: P(not A) = 1 − P(A); P(A ∪ B) = P(A) + P(B) − P(A ∩ B); conditional probability P(A|B) = P(A ∩ B) / P(B); A and B are independent if P(A ∩ B) = P(A)·P(B).

Expectation is the long-run average: E[X] = Σ x·P(x).

Real-life example

A slot machine in an RL "bandit" problem pays ₹10 with probability 0.3 and ₹0 otherwise. Expected reward = 10 × 0.3 = ₹3 per pull. An RL agent must estimate this number by trying the machine repeatedly. Weather forecasts ("70% chance of rain") are also probabilities.

Why RL needs it

Environments are uncertain: the same action can lead to different next states and rewards. RL maximizes expected total reward, so every algorithm is built on probability.

Simulation: Law of Large Numbers

Flip a coin many times. The running fraction of heads settles near the true probability p.

Numericals

Q1. A fair coin is tossed 3 times. Find P(at least one head).P(no head) = (1/2)³ = 1/8, so P(at least one) = 1 − 1/8 = 7/8.
Q2. A fair die is rolled. Find E[X].(1+2+3+4+5+6)/6 = 3.5.
Q3. P(A)=0.5, P(B)=0.4, P(A∩B)=0.2. Find P(A|B). Are A and B independent?P(A|B) = 0.2/0.4 = 0.5. Since P(A)P(B) = 0.2 = P(A∩B), they are independent.
Practice: A bandit arm pays 5 with probability 0.6 and −2 otherwise. Find the expected reward.5(0.6) + (−2)(0.4) = 3 − 0.8 = 2.2.

2. Random Variables and Probability Distributions

Basics

A random variable (RV) is a rule that assigns a number to each outcome. Example: X = number of heads in 3 tosses.

Discrete RV: takes countable values; described by a PMF P(X = x). Continuous RV: takes any value in a range; described by a PDF f(x), where probability is the area under the curve and total area = 1.

E[X] = Σ x·P(x)   |   Var(X) = E[X²] − (E[X])²   |   σ = √Var

Bernoulli(p): one trial, success with probability p. Mean p, variance p(1−p).
Binomial(n, p): number of successes in n independent trials. P(X=k) = C(n,k) pᵏ (1−p)ⁿ⁻ᵏ. Mean np, variance np(1−p).
Normal(μ, σ²): the bell curve. About 68% of values lie within 1σ of the mean and 95% within 2σ.

Real-life example

A factory makes bulbs and 5% are defective. In a box of 10, the number of defective bulbs is Binomial(10, 0.05). Heights of students follow a roughly normal curve. In RL, policies output a probability distribution over actions, such as a Normal distribution for a robot's steering angle.

Simulation: Binomial distribution

Numericals

Q1. X ~ Binomial(5, 0.5). Find P(X=2).C(5,2)(0.5)²(0.5)³ = 10/32 = 0.3125.
Q2. X ~ Binomial(20, 0.1). Find mean and variance.Mean = 20(0.1) = 2. Variance = 20(0.1)(0.9) = 1.8.
Q3. Test marks are Normal with μ=60, σ=10. Roughly what percent score between 50 and 70?That is μ ± 1σ, so about 68%.

3. Bayes' Rule and Inference

Basics

Bayes' rule updates a belief after seeing evidence. You start with a prior, observe data, and get a posterior.

P(H|E) = P(E|H) · P(H) / P(E), where P(E) = P(E|H)P(H) + P(E|not H)P(not H)

H is the hypothesis, E is the evidence. P(E|H) is the likelihood. Inference means drawing conclusions about hidden quantities from observed data.

Real-life example

A disease affects 1% of people. A test detects it 90% of the time when present, but also gives a false alarm for 9% of healthy people. If you test positive, the chance you are actually ill is only about 9%, because healthy people vastly outnumber sick people. In RL, an agent uses the same idea to guess its hidden state from noisy sensors (belief state in POMDPs, Kalman filters).

Simulation: Medical test

Numericals

Q1. Use the numbers above (1%, 90%, 9%). Find P(ill | positive).P(E) = 0.9(0.01) + 0.09(0.99) = 0.009 + 0.0891 = 0.0981. Posterior = 0.009/0.0981 ≈ 0.092 (9.2%).
Q2. Machine A makes 60% of items, B makes 40%. Defect rates 2% and 5%. A random item is defective. Find P(from B).P(D) = 0.6(0.02) + 0.4(0.05) = 0.032. P(B|D) = 0.02/0.032 = 0.625.
Practice: Email spam rate is 30%. The word "free" appears in 60% of spam and 10% of normal mail. Find P(spam | "free").Numerator 0.6(0.3) = 0.18. P(E) = 0.18 + 0.1(0.7) = 0.25. Answer = 0.72.

4. Stochastic Processes and Markov Chains

Basics

A stochastic process is a sequence of random variables over time. A Markov chain is a process where the next state depends only on the current state (the Markov property): P(Sₜ₊₁ | Sₜ, Sₜ₋₁, …) = P(Sₜ₊₁ | Sₜ).

The transition matrix P has entries Pᵢⱼ = P(next = j | now = i); each row sums to 1. If the distribution now is the row vector π, then after one step it is πP, and after n steps πPⁿ.

The stationary distribution satisfies π = πP. Under mild conditions, the chain converges to it no matter where it starts.

Real-life example

Weather: if today is sunny, tomorrow is sunny with probability 0.8. Google PageRank models a person randomly clicking links. In RL, a Markov Decision Process adds actions and rewards to a Markov chain: the next state depends on the current state and the chosen action.

Simulation: Sunny/Rainy chain

The chart shows P(Sunny) over 20 days, starting from a sunny day. It converges to the stationary value.

5. Linear Algebra Fundamentals

Basics

A vector is an ordered list of numbers, such as v = (3, 4). Geometrically it is an arrow with a length and a direction. A matrix is a rectangular grid of numbers that transforms vectors.

Operations: vector addition (add component-wise); scalar multiplication (stretch or shrink); dot product a·b = a₁b₁ + a₂b₂ + …; matrix times vector: each output entry is a row of the matrix dotted with the vector; matrix product AB needs columns of A = rows of B; transpose Aᵀ swaps rows and columns; identity matrix I leaves vectors unchanged.

Length |v| = √(v·v)   |   cos θ = (a·b) / (|a||b|)

Real-life example

A movie can be a vector of ratings: (action = 8, comedy = 2, romance = 5). Two movies with a high cosine similarity are alike, which is how recommendation systems work. In RL, a state is usually a feature vector and a neural network layer is a matrix multiplication.

6. Vector Spaces and Inner Products

Basics

A vector space is a set of vectors where you can add any two and scale any one, and the result stays inside the set (closure), along with the usual rules (zero vector, additive inverse, associativity, distributivity). Examples: ℝ², ℝ³, all polynomials of degree ≤ 2.

A subspace is a vector space inside a larger one; it must contain the zero vector. The span of vectors is all their linear combinations. A basis is a minimal set that spans the space; the number of vectors is the dimension.

An inner product ⟨u, v⟩ generalizes the dot product. It must be symmetric, linear, and positive (⟨v, v⟩ > 0 for v ≠ 0). It gives a norm ‖v‖ = √⟨v, v⟩, distance ‖u − v‖, and a notion of orthogonality (⟨u, v⟩ = 0).

Cauchy–Schwarz: |⟨u, v⟩| ≤ ‖u‖‖v‖   |   Triangle: ‖u + v‖ ≤ ‖u‖ + ‖v‖

Real-life example

Colors on a screen live in a 3D vector space (R, G, B): any color is a combination of the three basis colors. A line through the origin in 3D is a subspace, but a line that misses the origin is not. In RL, value functions are often approximated as a combination of basis features, so the value function lives in the span of those features.

Numericals

Q1. Is the line y = 2x a subspace of ℝ²? Is y = 2x + 1?y = 2x contains (0,0) and is closed under addition and scaling: yes. y = 2x + 1 misses the origin: no.
Q2. Find the norm of (3, 4) and the angle between (1, 0) and (1, 1).‖(3,4)‖ = 5. cos θ = 1/(1·√2) = 0.707, so θ = 45°.
Practice: Are (2, 3) and (3, −2) orthogonal?2(3) + 3(−2) = 0, so yes.

7. Linear Independence and Projections

Basics

Vectors v₁, …, vₖ are linearly independent if c₁v₁ + … + cₖvₖ = 0 only when all cᵢ = 0. If one vector can be built from the others, they are dependent. In ℝⁿ, more than n vectors are always dependent. For a matrix, rank is the number of independent columns, and for a square matrix, det ≠ 0 means independent columns.

The projection of b onto a is the part of b that points along a:

proj_a(b) = (a·b / a·a) · a   |   error e = b − proj_a(b) is orthogonal to a

The projection is the closest point to b on the line through a. This is the idea behind least squares: solve AᵀA x = Aᵀb to find the best fit when Ax = b has no exact solution.

Real-life example

The shadow of a stick on the ground at noon is its projection onto the ground. Fitting a straight line to noisy data points is a projection of the data vector onto the space of lines. In RL, linear function approximation projects the true value function onto the span of the features.

8. Eigenvalues and Spectral Analysis

Basics

Most vectors change direction when a matrix acts on them. An eigenvector v keeps its direction and is only scaled by the eigenvalue λ:

A v = λ v  ⇒  det(A − λI) = 0 (characteristic equation)

For a 2×2 matrix: λ² − (trace)λ + det = 0. Also, sum of eigenvalues = trace and product = determinant.

Spectral analysis studies the eigenvalues (the spectrum). A symmetric matrix has real eigenvalues and orthogonal eigenvectors, so A = QΛQᵀ (spectral theorem). This leads to PCA, the SVD, and stability analysis. A Markov transition matrix always has eigenvalue 1, and its eigenvector is the stationary distribution. If every |λ| < 1, repeated multiplication shrinks to zero; if some |λ| > 1, it blows up.

Real-life example

A swing or bridge has natural frequencies, which are eigenvalues of the system; pushing at that frequency causes resonance. PCA finds the directions along which data varies the most, using eigenvectors of the covariance matrix. In RL, eigenvalues of the transition matrix decide how fast a chain mixes and whether an iterative algorithm converges.
